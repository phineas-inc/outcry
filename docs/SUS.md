# SUS kit for Outcry

The System Usability Scale is a 10-question survey (1 = strongly disagree … 5 = strongly agree) taken **after** a participant has tried the product. It yields a 0–100 score.

## 1. Test plan (about 20 minutes per person)

Recruit 5–8 people (include at least one screen-reader or keyboard-only user and some German speakers). Do not explain the site first. Give these tasks, one at a time, and note where they hesitate or fail:

1. Find the protest that is happening in a country you pick, using the map.
2. Open it and say which side of the media (left/center/right) covers it the most.
3. Cast a vote of strength 2 on "Support the cause?" (hint: you must read all sides first).
4. Find out how many Voice you have left, and explain what that means.
5. Switch the site to German, then to the dark theme.
6. Find and use the option to delete your data.

Record: task success (yes/no/with help), time, errors, quotes. Then give the survey below.

## 2. Questionnaire

| # | English | Deutsch |
|---|---|---|
| 1 | I think that I would like to use this website frequently. | Ich kann mir gut vorstellen, diese Website regelmäßig zu nutzen. |
| 2 | I found the website unnecessarily complex. | Ich fand die Website unnötig komplex. |
| 3 | I thought the website was easy to use. | Ich fand die Website einfach zu bedienen. |
| 4 | I think that I would need the support of a technical person to be able to use this website. | Ich glaube, ich würde die Hilfe einer technisch versierten Person brauchen, um diese Website nutzen zu können. |
| 5 | I found the various functions in this website were well integrated. | Ich fand, dass die verschiedenen Funktionen der Website gut aufeinander abgestimmt sind. |
| 6 | I thought there was too much inconsistency in this website. | Ich fand, dass es auf der Website zu viele Unstimmigkeiten gibt. |
| 7 | I would imagine that most people would learn to use this website very quickly. | Ich kann mir vorstellen, dass die meisten Menschen diese Website sehr schnell zu nutzen lernen. |
| 8 | I found the website very cumbersome to use. | Ich fand die Website sehr umständlich zu nutzen. |
| 9 | I felt very confident using the website. | Ich fühlte mich bei der Nutzung der Website sehr sicher. |
| 10 | I needed to learn a lot of things before I could get going with this website. | Ich musste viele Dinge lernen, bevor ich mit der Website loslegen konnte. |

The German wording is a plain translation for convenience; a published, validated German SUS exists if you need results to be citable.

## 3. Scoring

For each participant: odd items (1,3,5,7,9) contribute `answer − 1`; even items (2,4,6,8,10) contribute `5 − answer`. Add the ten contributions and multiply by **2.5** → a score from 0 to 100. Average across participants.

| Score | Rough meaning |
|---|---|
| < 51 | Poor |
| 51–67 | Below average |
| 68 | Industry average |
| 68–80 | Good |
| > 80 | Excellent |

With 5–8 participants the number is indicative, not statistically precise. The task notes usually tell you more than the score.
